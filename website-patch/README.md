## Netlify deployment

Upload the entire folder to Netlify or connect it to a repository. No build command is required.

The form name is:

`urban-eye-project-inquiry`

After deployment, submit a test inquiry and verify:

1. The submission appears in Netlify Forms.
2. Email notifications are configured.
3. The thank-you redirect works.
4. Mobile navigation works.
5. Every contact link is correct.

## V5 hero video restoration

The homepage now includes a real HTML5 hero video with:

- `assets/urban-eye-hero.webm` — primary browser format
- `assets/urban-eye-hero.mp4` — H.264 fallback
- `assets/urban-eye-hero-poster.webp` — static first-paint and reduced-motion fallback

The loop is eight seconds at 24fps and uses very subtle reversible motion derived from the approved original hero artwork. It returns to the opening composition for continuous looping.

The supplied project did not contain the previously referenced original WebM or MP4 files, so this version generates and bundles a new restrained cinematic loop from the approved hero image rather than pretending the missing source video was available.
